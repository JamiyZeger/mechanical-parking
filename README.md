# 机械车位大揭秘 🏗️

给孩子的「升降横移式立体车库」互动教学网页，单文件 HTML、零依赖。

**在线体验（GitHub Pages）**：https://jamiyzeger.github.io/mechanical-parking/

## 玩法
- **选车库**：两层 / 三层切换；第一层车位数 2~6 可选（顶层比下面多 1 个车位）
- **停车**：点任意空车位 → 下面的车板横移让路 → 铁链吊车板下降 → 小汽车开进去
- **取车**：点小汽车（或「随机开走一辆」按钮），车从右边开出画面
- **观察铁链**：二、三层车板分别吊在各自的横梁上，和真实车库一样
- **懒动规则**：横移、升降都**不复位**——车板让路后停在原地（💤 标记），下次挡路才被迫移开，贴近实际使用

## 规则
参考真实「升降横移类机械式停车设备」（PSH）：顶层只升降、中间层升降+横移、底层只横移；
除顶层外每层留一个交换空位，存取取车时目标位到空位之间的载车板依次横移一格让出通道。
